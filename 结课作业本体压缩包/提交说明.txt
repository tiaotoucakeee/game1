交互叙事理论 - ARG 平行实境网页解密游戏
========================================

[最快开始 - 本地运行]
1. 电脑需已安装 Node.js 24+（https://nodejs.org/）
2. 双击「启动游戏.bat」
3. 首次运行会自动安装依赖，稍等 1-3 分钟
4. 浏览器将自动打开游戏；关闭黑色命令行窗口即停止

[在线体验（无需安装）]
https://papaya-cocada-c8eb16.netlify.app

[手动运行（可选）]
npm install
npm run dev
浏览器打开 http://localhost:3000

[文档]
docs/player-walkthrough.docx - 玩家攻略
docs/player-walkthrough.md   - 攻略 Markdown

[说明]
- 进度保存在浏览器 localStorage
- 推荐 Chrome / Edge
- 线上 Ani 为演示模式，不影响通关
